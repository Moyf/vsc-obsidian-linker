# Start Here

Welcome to the **Obsidian Linker example vault**. This folder is a mini vault for trying every feature of the Obsidian Linker extension in VS Code.

## How to use

1. Open this folder in VS Code (`examples/en`).
2. Hold `Ctrl` (`Cmd` on macOS) and click any wikilink below to jump to its target.
3. Hover over links or image embeds to see the hover card and image previews.
4. Click the `Obsidian` button in the bottom-right status bar to send the current file to Obsidian.
