## 开始测试

下面的链接适合测试编辑器的 Ctrl+Click、悬浮卡片，以及 Preview 的左键、右键菜单和中键打开。

### 文本双链与锚点

- 普通笔记：[[这个周末的灵感]]
- 显示别名：[[这个项目的计划|项目计划]]
- 目标标题与别名：[[这个项目的计划#下一步|直接查看下一步]]
- 当前文件标题：[[#图片与尺寸|跳到本页的图片区]]
- 编码文件名与英文标题：[[English%20Note#Small steps|English Note · Small steps]]
- 块引用：[[阅读笔记#^quote|阅读摘录]]（目前打开文件，尚不定位到块）

### 图片与尺寸

PNG，只指定宽度：

![[星夜.png|480]]

PNG，指定宽度与高度：

![[星夜.png|360x200]]

SVG，矢量图片：

![[链接流程.svg|560]]

普通图片文件链接：[[星夜.png|打开 PNG 文件]]

### 表格中的双链

别名及图片尺寸中的 `|` 在 Markdown 表格内需要写成 `\|`。

| 场景 | 实际效果 |
| --- | --- |
| 别名 | [[这个周末的灵感\|周末灵感]] |
| 标题 | [[这个项目的计划#下一步\|下一步]] |
| 图片 | ![[星夜.png\|240]] |

### 未找到或被排除

下面三项应显示灰色文字，并能悬浮查看原因。

- [[尚未创建的笔记#新的起点|尚未创建的笔记]]
- ![[不存在的图片.webp|尚未上传的图片]]
- [[被排除的笔记|已存在，但被索引设置排除]]

### 保持原样的情况

非图片嵌入目前保留原文：![[这个周末的灵感]]

行内代码保持原样：`[[这个周末的灵感]]`、`![[星夜.png]]`、`「「`。

```markdown
[[这个周末的灵感|这里不应变成链接]]
![[星夜.png|300]]
「「
```

转义的双链保持原样：\[[这个周末的灵感]]。
