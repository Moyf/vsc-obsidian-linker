## 说明

- 支持格式：PNG / JPEG / GIF / WebP / SVG / BMP / AVIF
- 图片可以放在任意附件目录，按工作区相对路径或文件名查找，显式路径优先
- 行内代码与代码块中的嵌入不会被解析
- 使用图片预览时请保持 `obsidian-linker.indexOnlyMarkdown` 关闭，并确认 `indexExclude` / `indexLimit` 没有排除这些图片
