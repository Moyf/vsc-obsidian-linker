# 开始

欢迎来到 **Obsidian Linker 示例库**。本文件夹是一个迷你仓库，用来在 VS Code 中体验 Obsidian Linker 扩展的全部功能。

## 怎么用

1. 在 VS Code 中打开本文件夹（`examples/zh`）。
2. 按住 `Ctrl`（macOS 为 `Cmd`）点击下面的双链即可跳转。
3. 把鼠标悬停在链接或图片嵌入上，可以看到悬浮卡片与图片预览。
4. 点击右下角状态栏的 `Obsidian` 按钮，把当前文件发到 Obsidian 打开。
